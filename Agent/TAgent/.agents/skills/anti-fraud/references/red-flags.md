# 风险信号与快速判定

## 〇、主动嗅探触发词（无需用户主动提问）

**即使用户没有在问「这是不是诈骗」**，只要对话中出现下列词，就要插入风险提示，且不因「只是顺带提醒」而弱化强度：

> 转账、汇款、打款、垫付、保证金、解冻、手续费、验资、刷流水、验证码、密码、FaceTime、屏幕共享、远程控制、屏幕录制、安全账户、监管账户、对公走账、刷单、返利、稳赚、内幕、导师带单、贷款、放款、额度、退款、理赔、中奖、补贴、银行卡、征信、百万保障、到期扣费、跑分、日结兼职、无障碍权限

命中**一票否决项**（S01/S02/S03）→ 按诈骗强度输出强提醒卡；命中其他 → 给核实清单。

## 一、五问快速判定法

任何疑似场景，先问这五句。只要**第一问为「是」**，其余不必再问——直接判定诈骗。

| # | 问题 | 命中含义 |
|---|---|---|
| 1 | 对方是否要求转账到「安全账户」「监管账户」「验资账户」「对公账户走账」？ | **100% 诈骗**。任何机关、平台、银行都不存在此类账户 |
| 2 | 对方是否索要短信验证码、支付密码、银行卡密码、人脸/指纹验证？ | **100% 诈骗**。验证码 = 支付授权 |
| 3 | 对方是否要求屏幕共享、远程控制、开启「无障碍/辅助功能」？ | **100% 诈骗**。等于把手机交给对方 |
| 4 | 是否存在「先小额返利再大额投入」的节奏？ | 典型刷单/杀猪盘结构 |
| 5 | 是否在制造紧迫感（限时、逾期、冻结、坐牢、影响征信、名额仅剩）？ | 用于压缩思考时间，是所有骗局的通用放大器 |

## 三、风险等级换算

| 总分 | 等级 | 判定 | 处置 |
|---|---|---|---|
| ≥ 70 | 🔴 极高危 | 是诈骗 | 立即中止一切操作，进入止损流程 |
| 50 – 69 | 🟠 高危 | 高度疑似 | 停止转账，补充核实后再定；按诈骗处置 |
| 30 – 49 | 🟡 中危 | 存疑 | 暂停操作，通过官方渠道独立核实 |
| 15 – 29 | 🔵 低危 | 可疑 | 保持警惕，不泄露信息、不点链接 |
| < 15 | ⚪ 未见明显风险 | 暂未识别到诈骗特征 | 常规提醒 |

## 四、接触渠道风险速查

| 渠道 | 风险提示 |
|---|---|
| 境外来电（+00 / +852 / +853 / +886 等）自称境内官方 | 官方机关不会用境外号码致电。直接挂断 |
| 95/400 号码自称银行客服 | 号码可伪造（改号软件）。挂断后自行拨打官方客服号回拨核实 |
| 短信内含短链（t.cn / dwz.cn 等） | 域名不可验证。不点，自行 App 内操作 |
| 社交平台私信、评论区「内部渠道」 | 高发引流入口 |
| 快递面单扫码「领福利」 | 典型引流物 |
| 微信群 / QQ 群「任务群」「助力群」 | 刷单类主要入口 |
| 招聘平台「居家兼职、日结 300+」 | 刷单与跑分的主要伪装 |
| 短视/直播平台「导师带单」 | 虚假投资理财的主要入口 |

## 五、资金出口风险速查

资金出口越「不可逆、难追溯」，诈骗确定性越高：

1. **个人银行卡分散收款**（人卡分离、跨省、多卡轮换）→ 跑分洗钱特征
2. **对公账户收款但主体与业务不符**（新注册、无实际经营、跨类目）→ 空壳公司走账
3. **USDT / 虚拟货币** → 链上难冻结，追损难度极高
4. **购物卡卡密、游戏点卡** → 即时变现，几乎不可追
5. **现金 / 黄金邮寄、跑腿代收** → 规避电子留痕
6. **「向本人账户转账」也要警惕** → 屏幕共享 + 验证码情形下，钱在自己卡里也会被转走

## 六、易受害人群画像（用于宣防与机构重点保护）

| 人群 | 高发类型 | 针对性提醒 |
|---|---|---|
| 老年人 | 冒充公检法、虚假保健品、冒充子女出事、养老投资 | 官方机关不会电话办案；涉及钱一律与子女当面确认 |
| 学生 / 未成年人 | 游戏账号交易、明星粉丝返利、刷单兼职、冒充同学 | 任何「扫码领福利」先问家长 |
| 财会人员 | 冒充老板/领导要求转账 | 转账必须线下或电话二次确认，不认聊天软件指令 |
| 求职者 | 刷单兼职、培训贷、押金/服装费 | 任何入职前先交钱的都是诈骗 |
| 离异/单身中青年 | 杀猪盘（网恋 + 投资/博彩） | 未见过真人就谈投资 = 诈骗 |
| 小微企业主 | 冒充客户/供应商、虚假贷款、账户年检 | 变更收款账户必须电话回拨原联系人核实 |
| 留学生及家属 | 冒充使领馆、冒充子女被绑架/涉案 | 联系学校、同学交叉核实；使领馆不会要求转账 |

## 七、二次诈骗警示（被骗后必做提醒）

被骗者已在「易感名单」上，二次诈骗发生率极高。必须主动提醒：

- 声称「网警/黑客能帮你追回资金」「交保证金解冻」→ 诈骗
- 声称「维权律师/追损团队，先付服务费」→ 诈骗
- 声称「你的案子我们内部有人，打点费」→ 诈骗
- 声称「下载某某 App 登记退款」→ 诈骗
- **唯一合法路径**：到公安机关报案，凭受案回执查询进展

## 八、独立核实标准动作

任何自称官方的联系，一律按此核实，不沿用对方提供的联系方式：

1. 挂断 / 结束对话
2. 自行通过官方 App、官网公示号码、银行卡背面号码回拨
3. 要求对方提供工号、单位、事由，并自行致电官方核验
4. 涉及账户操作，登录官方 App 或到网点查询，不看对方发来的截图

## 九、反向证伪（防止误判，定级前必做）

命中信号不等于就是诈骗。定级前先问：**这个内容有没有一个合理的正常解释？**

| 场景 | 可能只是正常 | 判断分界 |
|---|---|---|
| 银行短信提到验证码 | 本人操作的正常验证 | 「把验证码告诉我」才是诈骗；验证码只应留在自己手机上 |
| 客服联系退款 | 平台真实售后 | 退款**原路退回**，要求先转账/下载 App 即为诈骗 |
| 领导要求转账 | 真实业务付款 | 必须经**已知号码回拨 + 双人复核**确认 |
| 朋友借钱 | 真实应急 | 必须视频或电话核实本人 |
| 高收益理财推销 | 持牌机构的合规产品 | 承诺**保本**高收益 / 收益来自拉人头 → 非法 |
| 陌生号码通知账户异常 | 银行真实风控 | 银行不索要密码与验证码，不要求转账验证 |

**规则**：有正常解释且**不附带任何风险动作要求**（转账、验证码、下载、共享）→ 判为低风险或绿色；只要附带风险动作要求，正常解释不成立，回到信号评分。

## 十、擦边球判定（合法 ≠ 诈骗，但也 ≠ 安全）

不要把所有「高压销售」都定性为诈骗，这会让真正的警告失去可信度。走这条推路：

1. **是否有真实可查的经营主体？**（统一社会信用代码、可在国家企业信用信息公示系统查到）
2. **是否有真实交付？**（商品/服务确实存在且可交付）
3. **是否有合规披露？**（价格、风险、退换货、合同条款明示）
4. **是否命中违法硬指标？**（保本高收益、拉人头计酬、虚假资质、无真实产品、要求向个人账户付款）

- 三项齐全 + 未命中硬指标 → **黄色**：提示核实、谨慎决策，**不定性违法**
- 命中任一硬指标 → **红色**：有公司主体也不能洗白
- 是否违法的最终认定权在监管与司法机关，技能只做风险分级

## 十一、未收录类型处理（禁止编造）

当描述明显异常（高压、胁迫、要求保密、要求非常规操作），却**匹配不上图谱中任何一类**时：

1. **不得默认判安全**，也不得编造一个骗局类型名称
2. 主动做广谱检索（公开预警、同类举报）核验
3. 输出标注「**疑似新型骗局 / 知识库未收录**」，结论标 `[推断]` 或 `[待核实]`
4. 用通用信号清单逐条说明命中/未命中，按特征判定等级
5. 明确建议以官方渠道（96110 / 110）核实

## 十二、信息不足时的降级规则（禁止硬判）

发问方式：**一次性抛出全部必问字段的清单**，不连环追问。

| 必问字段 | 作用 |
|---|---|
| 对方自称身份、能否核实 | 判断是否冒充官方/熟人 |
| 对方要求你做什么 | 判断是否存在转账/验证码/下载/共享 |
| 是否涉及钱（金额、收款方性质） | 决定走拦截还是止损 |
| 是否要求点链接/下载 App/扫码/共享 | 判断链路风险 |
| 是否施压（限时、威胁、要求保密） | 判断是否冒充官方套路 |
| 是否已付款或已泄露证件/卡/验证码 | 已发生则直接进入止损 SOP |

**上限**：1 轮批量澄清 + 1 轮补充。仍然不足 → 输出黄色「暂无法判定」卡：

- 列明「还缺什么」
- 标注 `[待核实]`
- 给出官方核验渠道（96110 / 110 / 官方 App）
- 明确提示：**在补齐前，不转账、不点链接、不提供验证码**

禁止在信息不足时强行给出红色或绿色的确定结论。
