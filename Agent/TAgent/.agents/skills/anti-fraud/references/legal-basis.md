# 法律依据与罪名

> 用途：给出定性参考与沟通口径。**具体认定与量刑以公安机关、检察院、法院为准**，本文不构成法律意见。

---

## 一、核心法律

### 《中华人民共和国反电信网络诈骗法》
- 通过：2022 年 9 月 2 日；施行：2022 年 12 月 1 日
- 定位：反电诈领域第一部专门法律
- 要点：
  - 明确「电信网络诈骗」定义与全链条治理思路（通信、金融、互联网三线并管）
  - 规定电话卡、银行卡、支付账户、互联网账号的**实名制与数量管理**
  - 禁止任何单位和个人**出租、出借、出售**电话卡、银行卡、支付账户、互联网账号
  - 建立**涉诈异常账户与可疑交易监测、拦截、处置**机制
  - 规定预警劝阻、紧急止付、快速冻结、资金返还制度
  - 明确各行业主体未履职的行政处罚与民事责任
  - 对出境从事电诈、为电诈提供帮助的行为设定责任

### 《中华人民共和国刑法》相关罪名

| 罪名 | 法条 | 适用情形 | 量刑 |
|---|---|---|---|
| 诈骗罪 | 第 266 条 | 以非法占有为目的，虚构事实、隐瞒真相骗取公私财物 | 数额较大：3 年以下；数额巨大或情节严重：3-10 年；数额特别巨大或情节特别严重：10 年以上或无期 |
| 帮助信息网络犯罪活动罪（帮信罪） | 第 287 条之二 | 明知他人利用信息网络实施犯罪，为其提供互联网接入、服务器托管、网络存储、通讯传输等技术支持，或提供广告推广、支付结算等帮助，情节严重 | 3 年以下有期徒刑或拘役，并处或单处罚金 |
| 掩饰、隐瞒犯罪所得、犯罪所得收益罪 | 第 312 条 | 明知是犯罪所得及其收益而予以窝藏、转移、收购、代为销售或以其他方法掩饰、隐瞒 | 一般：3 年以下；情节严重：3-7 年 |
| 侵犯公民个人信息罪 | 第 253 条之一 | 非法获取、出售、提供公民个人信息，情节严重 | 3 年以下；情节特别严重：3-7 年 |
| 妨害信用卡管理罪 | 第 177 条之一 | 非法持有他人信用卡、使用虚假身份证明骗领信用卡等 | 3 年以下；数量巨大或有严重情节：3-10 年 |
| 非法利用信息网络罪 | 第 287 条之一 | 设立用于实施诈骗的网站、通讯群组，或发布涉诈信息情节严重 | 3 年以下 |

## 二、高频场景定性速查

| 场景 | 可能定性 | 说明 |
|---|---|---|
| 出借/出售自己的银行卡、手机卡 | 帮信罪 | 「不知情」通常不免责，「应当知道」即可认定；大量司法实践中以牟利、异常交易、明显低价等推定明知 |
| 用自己收款码/账户帮人「跑分」赚佣金 | 帮信罪，严重的可能构成掩隐罪 | 流水金额与获利是重要量刑情节 |
| 帮人取现、转移现金（车手） | 掩隐罪 | 直接参与转移犯罪所得 |
| 出租营业执照、对公账户 | 帮信罪 + 行政责任 | 还会被列入金融信用惩戒名单 |
| 组织他人办卡出售（卡头卡贩） | 妨害信用卡管理罪 / 帮信罪 | 从重情节 |
| 出售/提供公民个人信息 | 侵犯公民个人信息罪 | 50 条敏感信息或 500 条一般信息可达入罪门槛（司法解释口径，以现行有效解释为准） |
| 被骗后参与「代付」转钱给陌生人 | 视明知程度，可能涉帮信 | 需立即停止并主动说明 |
| 开发/运维涉诈 App、架设 GOIP | 帮信罪、非法利用信息网络罪 | 技术中立不免责 |

## 三、常见误解澄清

| 误解 | 事实 |
|---|---|
| 「我又没骗人，只是借个卡，不犯法」 | 出借银行卡为诈骗提供支付结算帮助，可直接构成帮信罪 |
| 「我不知道对方是骗子」 | 认定标准是「明知或应知」。明显低于市场价的报酬、异常操作要求、他人代持等均可推定应知 |
| 「被骗的钱，银行/平台必须赔给我」 | 需看机构是否尽到安全义务与是否存在过错；不能一概而论，可通过投诉、调解、诉讼主张 |
| 「金额小，报警没用」 | 电信网络诈骗可并案侦查，小额报案是重要线索来源；且报案是止付的前提 |
| 「被诱导网贷的钱不用还」 | 与金融机构的债权债务关系不因被骗自动消灭，需及时沟通并保留报案凭证，通过合法途径处理 |
| 「把卡借出去被冻结，解冻就行」 | 涉案账户可能被采取金融信用惩戒措施，5 年内限制新开账户与非柜面业务 |

## 四、涉诈惩戒措施（金融信用惩戒）

对认定为出租、出借、出售账户或涉案的相关人员，可采取：
- 5 年内暂停其银行账户非柜面业务、支付账户所有业务
- 5 年内不得新开立账户
- 纳入金融信用信息基础数据库与相关信息共享平台

申诉途径：认为认定有误的，可向作出认定的公安机关或相关机构提出申诉。

## 五、报案与追损的法律流程要点

1. **报案** → 公安机关受案（出具受案回执）→ 初查 → 是否立案
2. **紧急止付 / 冻结**：公安机关可依法对涉案账户采取止付、冻结措施
3. **资金返还**：案件侦破后，依法对权属明确的被骗资金按程序返还被害人
4. **被害人诉讼权利**：可委托代理人、提起附带民事诉讼、查询案件进展
5. **法律援助**：符合条件的可申请法律援助，公共法律服务热线 **12348**
