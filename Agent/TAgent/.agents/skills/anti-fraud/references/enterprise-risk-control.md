# 机构侧风控与合规

适用：商业银行、非银支付机构、清算机构、电信业务经营者、互联网服务提供者、企业内控与财务部门。

> 本文件只提供**识别、拦截、处置与合规**视角的方法。任何涉及规避监管、帮助资金脱敏的内容不在范围内。

---

## 一、法定职责速览（《反电信网络诈骗法》）

| 主体 | 核心义务 |
|---|---|
| 银行业金融机构、非银行支付机构 | 建立客户尽职调查、开户数量管理、异常账户监测、交易风险提示、涉诈资金拦截与协助止付冻结 |
| 电信业务经营者 | 落实电话用户实名制、物联网卡管理、境外来电与改号治理、涉诈号码处置 |
| 互联网服务提供者 | 账号实名、涉诈 App 与网址监测处置、涉诈信息巡查、为公安机关提供技术支持和协助 |
| 任何单位和个人 | 不得出租、出借、出售电话卡、银行卡、支付账户；不得帮助他人转账套现 |

**责任后果**：未履行义务的机构可被责令改正、警告、罚款；情节严重的对直接负责的主管人员和其他直接责任人员处罚，并可暂停相关业务。

## 二、涉诈账户识别特征

### 2.1 开户侧（静态特征）

| 维度 | 可疑特征 |
|---|---|
| 主体年龄/职业 | 高龄或低龄开户与大额交易不匹配；职业、收入与交易规模严重不符 |
| 注册信息 | 新注册主体（开业 < 3 个月）、注册资本虚高、经营范围与实际交易类目不符、注册地址为集群地址 |
| 批量特征 | 同一地址、同一联系电话、同一 IP、同一设备注册多个主体；法定代表人交叉任职多家空壳公司 |
| 开户行为 | 短时间内集中开户、开户后立即申请开通大额/公转私权限、不愿临柜、回避尽职调查 |
| 名单命中 | 命中公安涉诈黑名单、法院失信、检察院涉案账户、行业风险信息共享名单 |

### 2.2 交易侧（动态特征）

| 特征 | 典型表现 |
|---|---|
| **快进快出** | 资金到账后数分钟至数小时内全额转出，账户不留余额 |
| **过渡性质** | 只做中转，无工资代发、无税费、无经营性支出 |
| **小额测试** | 先 1 元 / 10 元试探，成功后立即大额转入 |
| **分散转入集中转出 / 集中转入分散转出** | 典型的归集与拆分结构 |
| **夜间高频** | 0:00–6:00 集中交易，与正常营业时间背离 |
| **人卡分离** | 开户地、交易地、登录 IP 地三者长期不一致；IP 在境外或涉诈高发地区 |
| **交易对手异常** | 对手分散且多为新账户、跨行跨省、与主营无关 |
| **金额规避** | 刻意低于报送或审核阈值（如略低于 5 万、20 万） |
| **备注异常** | 备注「往来款」「借款」「货款」但无对应合同发票；或备注带货、博彩暗语 |
| **出金去向** | 流向虚拟货币 OTC、境外、游戏充值、直播打赏、大宗消费卡 |

### 2.3 设备与行为侧

- 同一设备/IP 控制大量账户；设备指纹重复、模拟器、改机工具特征
- 登录环境存在 VPN、代理、境外 IP、GOIP 号段
- 操作节奏机械（固定间隔、无浏览行为、直奔转账）
- 短信验证码被转发、存在「设备农场」特征

## 三、交易监测规则示例

> 以下阈值为**示例**，必须结合本机构客群基线、交易量级与误报容忍度调参，不可直接上线。

| 规则 ID | 规则 | 判定逻辑示例 | 处置 |
|---|---|---|---|
| R01 | 新户大额快进快出 | 开户 < 30 天 且 入账后 2 小时内转出 ≥ 入账额 90% 且 金额 ≥ 阈值 A | 延迟到账 + 人工复核 |
| R02 | 小额试探 | 1 元级入账后 30 分钟内出现 ≥ 阈值 B 的入账 | 加强尽调 |
| R03 | 夜间异常 | 0:00–6:00 累计转出 ≥ 阈值 C 且 占比异常 | 限额 + 提示 |
| R04 | 分散归集 | 24 小时内 ≥ N 个不同付款人转入同一账户，且转入后立即集中转出 | 冻结待核 |
| R05 | 人卡分离 | 交易地/登录地与常住地长期不一致，或 IP 命中高风险地区 | 限制非柜面交易 |
| R06 | 规避报送 | 多笔金额集中在阈值下方（如 4.9 万 × 多次） | 合并计算并上报 |
| R07 | 对手风险 | 收款方命中涉诈/涉案名单或行业共享风险名单 | 交易拦截 + 风险提示 |
| R08 | 异常提额 | 开户后短期内频繁申请提额、开通大额权限 | 重新尽调 |
| R09 | 商户类目错配 | 交易金额/频率/时段与商户类目基线严重偏离 | 延迟结算 + 现场巡检 |
| R10 | 出金高危去向 | 流向虚拟货币、境外、赌博高发商户、预付卡 | 拦截 + 报告 |

**规则运营要点**：
- 建立**效果回归**机制：统计每条规则的命中量、查实率、误报率、拦截金额，按月淘汰低质规则
- 黑白灰名单分层管理，名单有效期与退出机制明确
- 保留完整决策日志，满足可审计与监管检查要求

## 四、商户准入与存续管理

1. **准入**：营业执照与经营地址核验、法人/受益所有人识别、经营类目与实际场景一致性、现场巡检留痕
2. **存续**：交易基线建模（金额、时段、地域、退款率）、异常偏离告警、定期复检证照
3. **高危类目重点管控**：虚拟充值、预付卡、玉石文玩、大宗商品、医美、招商加盟、代付代收
4. **处置梯度**：风险提示 → 限制交易额度/频次 → 延迟结算 → 暂停受理 → 终止合作并上报
5. **涉案联动**：确认涉诈后立即冻结待结算资金，配合公安机关查询、止付、冻结、扣划，保留全部材料

## 五、涉诈资金链与黑产术语

| 术语 | 含义 |
|---|---|
| 卡头 / 卡贩 | 收购、组织他人开办银行卡、电话卡并转卖的中间人 |
| 卡四件套 | 银行卡 + U 盾/密码器 + 手机 SIM 卡 + 身份证，成套出售用于过账 |
| 跑分 | 用个人收款码/账户为非法资金代收代付，按流水抽成 |
| 水房 | 专门做资金拆分、混同、清洗的环节 |
| 车手 | 负责线下取现、转移现金的人员 |
| GOIP / 猫池 | 将境外网络信号转为本地电话/短信的设备，用于隐藏位置 |
| 料子 / 料 | 被非法获取的个人信息（姓名、手机、身份证、银行卡） |
| 话术脚本 | 诈骗团伙内部的标准对话流程，分角色、分阶段 |
| 盘口 | 虚假投资/博彩平台后台，可篡改行情与出金权限 |

**识别价值**：资金链上每一环都有可观测特征（开户批量性、过渡性流水、设备聚集、出金渠道），是模型与规则的主要抓手。

## 六、企业内控（非金融机构同样适用）

### 财会转账防诈（冒充老板 / 供应商变更账户）

1. **双人复核**：任何转账须经发起、复核两级，复核人不得与发起人为同一人
2. **白名单收款账户**：常用收款方维护白名单，新增或变更账户须走审批流程
3. **变更必须回拨核实**：供应商变更账户，必须用**合同或历史留存的号码**回拨，并向对方财务二次确认，不认聊天软件通知
4. **大额分级授权**：按金额设置审批层级，超限须线下签字或电话确认
5. **禁止事项**：不接受任何来自即时通讯工具的「加急」付款指令；不使用公共网络操作大额转账
6. **定期演练**：模拟冒充老板转账的钓鱼测试，纳入员工考核

### 员工与数据防诈

- 员工个人信息保护：最小化收集、加密存储、权限分级，防止成为「料子」来源
- 客服、销售等接触客户数据的岗位签署保密与合规承诺
- 定期反诈培训，重点岗位（客服、财务、风控、收银）每季度至少一次

---

## 七、反诈培训方案要点（可直接复用）

| 模块 | 对象 | 时长 | 核心内容 |
|---|---|---|---|
| 基础识骗 | 全员 | 45 min | 十大高发类型、五问判定法、验证码即授权 |
| 岗位专防 | 财务 / 收银 / 客服 | 60 min | 冒充老板转账核验流程、异常订单处置、客户劝阻话术 |
| 技术识别 | 风控 / 技术 | 90 min | 涉诈账户特征、设备指纹、规则调优 |
| 高管合规 | 管理层 | 45 min | 反电诈法义务、责任后果、事件处置与对外沟通 |

培训效果评估：钓鱼邮件/钓鱼消息模拟点击率、可疑事件上报量、成功劝阻案例数。

---

## 八、指标看板（建议）

- 涉诈拦截金额 / 笔数（按账户、商户、规则维度）
- 命中率、查实率、误报率（分规则）
- 平均拦截时长（从事发到止付）
- 公安协查响应时长、协查完成率
- 涉案账户数（存量/新增）、涉案账户占全量比
- 客户劝阻成功率（客服侧）
- 投诉与申诉处理时长

---

## 九、事件处置流程（机构侧）

1. **识别**：规则/模型告警、公安协查、客户投诉、外部名单
2. **初判**：30 分钟内完成账户画像复核（开户、流水、设备、对手）
3. **处置**：按梯度限制 → 冻结 → 延迟结算，同步留痕
4. **上报**：可疑交易报告、涉诈线索移送公安机关，重大案件即时报送
5. **配合**：查询、止付、冻结、扣划全程留痕，指定专人对接
6. **复盘**：每次事件输出复盘报告，回补规则与名单，更新基线
