# 诈骗手法图谱

按「引流渠道 → 关键话术 → 施压点 → 资金出口 → 硬伤识破点 → 止损关键动作」六段拆解。
匹配时优先看**资金出口**和**硬伤识破点**——话术会变，这两项最稳定。

---

## 1. 刷单返利类（发案量长期居首）

- **引流**：微信群/QQ 群任务、招聘平台「居家兼职日结」、快递面单扫码、短信「点赞员」
- **话术**：「抖音点赞关注，一单 3-8 元，日入 200+」「先垫付后返本金+佣金」
- **施压点**：前 1-3 单小额必返，建立信任；随后「连单/组合单/系统卡单」要求连续垫付，不完成则本金不退
- **资金出口**：个人银行卡（多地多人轮换）、二维码、个别要求购物卡
- **硬伤**：**任何要求垫付本金的兼职都是诈骗**；正规兼职不存在「垫付-返利」结构
- **止损**：立即停止垫付。已垫付的走止付流程。注意对方会以「缴税/解冻费/保证金」二次索要

## 2. 冒充电商物流客服类

- **引流**：境外或 95/400 号段来电、平台私信
- **话术**：「您购买的商品质量有问题，双倍理赔」「快递丢失，给您补偿」
- **施压点**：赔偿诱惑 + 「超时无法理赔」「需开启屏幕共享指导操作」
- **资金出口**：诱导开启网贷借款后转出；或索要验证码直接扣款
- **硬伤**：**退款只会原路退回支付账户，永远不会要求你先转账或下载 App**
- **止损**：挂断，登录购物 App 官方渠道查订单状态

### 2.1 百万保障 / 保险到期扣费（高频变种）

- **话术**：「您的微信/支付宝百万保障已到期，不关闭每月自动扣费 800 元」
- **硬伤**：百万保障是**免费且自动生效**的账户安全服务，不存在「到期续费」，也不可能被人工关闭收费
- **止损**：直接挂断。凡是主动打电话帮你「关闭扣费」的都是诈骗

## 3. 虚假贷款 / 代办信用卡类

- **引流**：贷款短信、网贷广告、仿冒银行 App
- **话术**：「无抵押、低息、秒批」「黑户可贷」
- **施压点**：先放款到 App 内「钱包」，再以「银行卡号错误、账户被冻结、需交保证金/解冻费/刷流水/验证还款能力」要求先转账
- **资金出口**：个人账户、「财务专用账户」
- **硬伤**：**正规贷款放款前不收取任何费用**；放款前要求「刷流水」= 洗钱
- **止损**：停止转账。已交费用的立即报案，并向放款 App 所属平台投诉

## 4. 冒充公检法类

- **引流**：境外来电、改号软件伪装成公安局号码
- **话术**：「你的身份证/银行卡涉嫌洗钱/诈骗案」「需要配合资金清查」
- **施压点**：保密要求（不得告诉家人）、出示伪造「通缉令/逮捕令/案件编号」、要求离开家人到酒店独自操作、要求「取保候审保证金」
- **资金出口**：「安全账户」「监管账户」，或诱导网贷后转出
- **硬伤**：**公检法机关不存在任何「安全账户」，绝不会电话办案、绝不会要求转账自证清白**
- **止损**：挂断，自行拨打 110 或到派出所核实

## 5. 虚假投资理财类（杀猪盘 / 杀鸟盘）

- **引流**：短视频/直播「导师带单」、社交平台私信、网恋关系
- **话术**：「内部消息」「跟着老师操作稳赚」「平台有内幕漏洞」
- **施压点**：先小额提现成功建立信任；再诱导加大投入；提现时以「账户异常、需缴税、需充值解冻」拒绝出金
- **资金出口**：多个人卡轮换、对公空壳账户、USDT 充值
- **硬伤**：**承诺保本高收益即非法**；能随意充值提现的「盘口」后台可篡改数据
- **止损**：立即停止充值，保存平台地址、充值记录、聊天记录、客服账号

### 5.1 网恋交友诱导投资/博彩（杀猪盘）

- 长期「养猪」：1-3 个月情感铺垫 → 偶然透露「我在某某平台赚了钱」→ 带你一起 → 大额收割
- **硬伤**：**未线下见过真人就谈投资 = 诈骗**；对方拒绝视频、拒绝见面、拒绝提供真实工作信息
- **止损**：停止充值，截图全部聊天与转账记录

## 6. 冒充领导 / 熟人 / 老板类

- **引流**：微信/QQ 冒充头像昵称、仿冒新号、AI 换脸视频通话
- **话术**：「我在开会/在外面，先帮我转笔钱到这个账户」「这是客户，你先垫付」
- **施压点**：领导身份带来的服从压力 + 「急，马上要」+ 「先转后补手续」
- **资金出口**：陌生个人账户、陌生对公账户
- **硬伤**：**任何来自聊天软件的转账指令都必须线下或电话二次确认**
- **止损（财会岗）**：先电话回拨该领导**已知号码**核实；企业须建立双人复核制度
- **AI 换脸变种破绽**：要求对方做指定动作（侧脸、用手遮半脸、念随机数字）；挂断后用原号码回拨

## 7. 虚假购物 / 服务类

- **引流**：二手平台、社交平台「内部渠道/低价代购」、演唱会门票代抢
- **话术**：「内部票」「海关扣押货」「先款后货更便宜」
- **施压点**：低价 + 「名额仅剩最后 2 张」
- **资金出口**：直接微信/支付宝转账、红包
- **硬伤**：**绕过平台担保交易 = 放弃全部维权可能**
- **止损**：停止转账，平台内举报订单

## 8. 网络游戏产品虚假交易类

- **引流**：游戏内喊话、交易平台/群
- **话术**：「低价出售账号/装备」「高价收购你的账号，走某某平台担保」
- **施压点**：伪造交易平台的「资金冻结」页面，要求充值解冻
- **资金出口**：平台充值、个人账户
- **硬伤**：**只在游戏官方或正规平台内交易**；任何「客服」私聊要求充值解冻都是诈骗
- **止损**：停止充值，向游戏官方与交易平台申诉

## 9. 虚假征信类

- **话术**：「你的校园贷记录未清零，影响征信」「不处理将列入失信名单」
- **施压点**：征信焦虑 + 冒充银保监会/央行/P2P 平台清退组
- **资金出口**：要求「验资」「转账到指定账户做清零对冲」
- **硬伤**：**个人征信由央行征信中心统一管理，任何机构和个人都无法通过转账修改**；征信查询免费且只能通过官方渠道

## 10. 裸聊敲诈类

- **引流**：社交软件「美女」主动搭讪 → 诱导裸聊并录屏 → 窃取通讯录
- **施压点**：「不给钱就把视频发给你通讯录所有人」
- **资金出口**：个人账户、USDT
- **硬伤**：**绝对不要转账，转账只会招来持续勒索**
- **止损**：立即拉黑、不转账、不回话；保存证据报案；通知通讯录亲友「我手机被植入木马、收到不雅信息请勿理会」

## 11. 中奖返利 / 福利类

- **话术**：「扫码抽奖中 iPhone」「明星粉丝福利群，转 100 返 1000」「转账 10 倍返还」
- **施压点**：贪利 + 限时 + 群内「托儿」晒返款截图
- **资金出口**：红包、个人收款码
- **硬伤**：**不存在「转账返利」**；群内晒单全是同伙

## 12. 冒充军警采购类

- **话术**：「我是某部队长，要采购物资，指定某供应商，你先垫付」
- **硬伤**：**军队采购一律走正规招标流程，不会指定供应商、不会要求个人垫付**
- **止损**：向当地武装部或市场监管部门核实

## 13. 虚假招聘 / 培训贷类

- **话术**：「高薪诚聘，需先交押金/服装费/体检费/培训费」「先培训后付款，包就业」
- **硬伤**：**《劳动合同法》禁止用人单位以任何名义向劳动者收取财物**；入职前先交钱 = 诈骗
- **变种**：诱导办理培训贷，贷到的钱直接划给机构

## 14. 冒充老师收费类（家长群）

- **引流**：潜入班级群、仿冒班主任头像昵称
- **话术**：「收取资料费/校服费 XXX 元，扫码支付」
- **硬伤**：先私聊班主任**已知号码**核实；学校收费有正式通知
- **止损**：群管理员开启入群验证，定期核对群成员

## 15. 冒充子女出事 / 被绑架类

- **话术**：「你孩子在我手上」「你孩子出车祸了，赶紧打钱到医院账户」
- **硬伤**：**保持通话，同时用另一部手机联系子女本人、学校、同学核实**
- **止损**：任何情况下先核实，不转账

## 16. 钓鱼短信类（ETC / 医保 / 社保 / 航班 / 违章）

- **话术**：「您的 ETC 已过期，点击链接重新认证」「医保账户将被停用」
- **施压点**：「今日逾期将失效」
- **资金出口**：链接内填写银行卡 + 验证码 → 直接扣款
- **硬伤**：**官方业务不会用短信短链办理**；域名不是官方域名
- **止损**：不点链接，自行通过官方 App 或网点办理

## 17. 冒充银行 / 支付平台风控类

- **话术**：「您的账户异常需解冻」「账户年检需验证」
- **施压点**：账户安全焦虑 + 「不处理将冻结」
- **硬伤**：**银行不会通过电话索要验证码、密码，不会要求转账验证**
- **止损**：挂断，拨打银行卡背面官方客服号

## 18. 虚假慈善 / 众筹类

- **话术**：伪造病患资料、伪造公募资质发起募捐
- **硬伤**：**公募募捐须具备公开募捐资格并在民政部指定平台发布**
- **核实路径**：全国慈善信息公开平台（慈善中国）核验

## 19. 境外高薪招聘类

- **话术**：「境外月薪 3 万、包机票、无需经验」
- **风险**：实为诱骗出境从事电诈、网赌，或沦为人口贩卖受害者
- **硬伤**：**境外务工须通过具备对外劳务合作经营资格的正规企业**

## 20. 代付 / 代收类（涉罪入口）

- **话术**：「帮我代收一笔钱，给你 3% 佣金」「租你的银行卡/收款码日结 500」
- **实质**：跑分洗钱，**不是被骗，是涉嫌犯罪**
- **法律后果**：帮助信息网络犯罪活动罪（帮信罪）
- **止损**：拒绝并保留证据举报。已参与的立即停止并主动向公安机关说明

## 21. 保健品 / 养生诈骗

- **引流**：免费体检、健康讲座、直播间、社区体验店、微信群「健康打卡」
- **话术**：「包治百病」「诺贝尔奖配方」「根治三高/癌症」「国家保密配方」
- **施压点**：健康焦虑 + 免费礼品的互惠心理 + 「专家」站台 + 会销现场氛围 + 「名额有限、今天特价」
- **资金出口**：个人账户、 POS 机刷卡、货到付款、养生馆预存卡
- **硬伤**：**食品不能宣传治疗功能，保健食品不得声称疾病预防/治疗功效**；正规药品有国药准字，保健品有「蓝帽子」标志，可在国家市场监管总局官网查询
- **止损**：停止购买，保留产品包装与宣传材料，向 12315 投诉

## 22. 免费诱饵引流类

- **引流**：免费领鸡蛋/米面、免费体检、免费旅游、免费讲座、扫码送礼品
- **本质**：不直接骗钱，而是把人引流到会销、投资群、刷单群，是多种骗局的**上游入口**
- **硬伤**：**所有「免费」的终点都是高价推销或投资诱导**
- **止损**：拒绝留手机号与身份证，不进群，不加微信

## 23. 以房养老骗局

- **话术**：「把房子抵押给保险公司/理财公司，每月领养老金，房子还是你的」
- **实质**：诱使老人签订抵押借款合同，资金进入理财平台后爆雷，房屋被强制执行
- **硬伤**：**正规以房养老（老年人住房反向抵押养老保险）只有持牌保险机构可开展，且房产所有权始终归老人**；任何要求签署借款合同、委托处置房产的都不是以房养老
- **止损**：立即核对已签合同性质（抵押/借款/委托公证），向银保监部门与律师核实，必要时申请撤销公证

## 24. 收藏品 / 纪念品骗局

- **话术**：「限量发行、权威机构监制、升值空间巨大」「我们帮你高价回购/拍卖」
- **施压点**：虚构拍卖成交记录、伪造鉴定证书、「回购期」承诺
- **硬伤**：**承诺回购即涉嫌非法集资或诈骗**；真藏品不会通过电话推销
- **止损**：停止购买，核验发行机构与鉴定机构资质

## 25. 票务类（演唱会 / 机票退改签）

- **话术**：「内部票/工作票」「代抢成功率高，先付定金」「航班取消，点击链接改签退费」
- **施压点**：「只剩最后 2 张」「半小时内不改签作废」
- **资金出口**：私下转账、钓鱼链接填写银行卡
- **硬伤**：**只在官方票务平台或航司官方渠道购买与改签**；票务转让须走平台
- **止损**：联系官方平台核实订单号

## 26. 注销校园贷 / 征信修复类

- **话术**：「你名下还有校园贷额度未注销，不处理影响征信」「我们帮你修复征信，包通过」
- **施压点**：征信焦虑 + 冒充平台客服/银保监部门
- **资金出口**：「验资对冲」转账、服务费
- **硬伤**：**征信记录任何机构和个人都无权删除或修改**；「征信洗白」「征信修复」全部是诈骗。个人每年可**免费**查询 2 次征信，异议可向央行征信中心或金融机构提出

## 27. 电诈工具人（跑分 / 帮信 / 架设设备）

- **话术**：「出租收款码日结 500」「借你的银行卡走个账给佣金」「在家插几张卡，日入 800」（GOIP/猫池）「帮发短信，一条 2 毛」
- **定性**：**这不是被骗，是涉嫌犯罪**——帮信罪、妨害信用卡管理罪
- **硬伤**：**出借银行卡、收款码、电话卡即违法**；「不知情」不能免责，牟利与异常情形可推定「应知」
- **止损**：拒绝并保留证据举报；已参与的立即停止、主动向公安机关说明

## 28. 资金盘 / 庞氏骗局

- **形态**：互助盘、拆分盘、分红盘、挖矿盘、众筹盘
- **话术**：「日化 1%」「静态收益 + 动态收益」「拉人头升级」
- **施压点**：早期正常兑付建立信任 + 团队计酬驱动拉新
- **硬伤**：**收益来自后来者的本金，而非任何真实经营，必然崩盘**；承诺固定高额收益 + 拉人头提成 = 非法集资 / 传销
- **止损**：停止投入，保存平台与团队长信息，向公安机关报案

## 29. 0 元购 / 消费全返资金盘

- **话术**：「0 元拿商品，钱全额返还」「消费多少返多少，排队返现」
- **实质**：商品价格虚高或需预存数倍资金，用后入者资金支付前入者返现
- **硬伤**：**返还资金来源于新用户本金，不是平台补贴**
- **止损**：停止预存，保留订单与宣传截图

## 30. 虚拟币 / 变种币 / 假交易所

- **话术**：「只涨不跌」「质押生息、挖矿躺赚」「RWA 代币、稳定币理财」「内部额度打新」
- **施压点**：伪造 K 线、伪造合约地址、假交易所 App 可先小额提现
- **资金出口**：USDT 充值到陌生地址、假钱包 App
- **硬伤**：**我国禁止虚拟货币相关业务活动为境内居民提供服务，境内不存在合法的虚拟币交易平台**；任何「保本币圈理财」都是诈骗
- **止损**：停止充值，保存钱包地址与交易哈希（虽难追回，但是报案线索）

## 31. 免费 / 低价旅游骗局

- **话术**：「99 元云南六日游」「0 元游还送大礼」
- **实质**：行程实为购物点 / 会销 / 讲座，或推销旅游 + 理财套餐
- **硬伤**：**明显低于成本价的旅游必然通过强制购物或金融收割回本**
- **止损**：选择正规旅行社并签订旅游合同，遭遇强制购物可向文旅部门投诉

## 32. 追星 / 粉丝群 / 直播打赏类（未成年人高发）

- **话术**：「加入粉丝群领明星周边」「帮主播做任务，完成任务返现」「扫码投票解锁福利」
- **施压点**：冒充明星助理/客服，以「泄露信息要赔偿」「操作失误导致账户被冻结」恐吓未成年人拿家长手机操作
- **资金出口**：小额转账、扫码、直播打赏
- **硬伤**：**任何要求未成年人拿家长手机扫码、开屏幕共享的都是诈骗**
- **止损**：家长开启支付限额与人脸验证，向平台申请未成年人打赏退款

## 33. 升学 / 留学 / 换汇类

- **话术**：「高考特招内部名额」「保录名校，先交运作费」「境外高薪、包机票」「私下换汇，汇率更优」
- **变种**：冒充留学生「自导自演绑架」向国内家属索要赎金（虚拟绑架）
- **硬伤**：**正规招生无「内部名额」**；**私下换汇违法且极易被骗**；接到「孩子被绑架」先联系学校、同学、使领馆核实
- **止损**：联系学校 / 使领馆核实；教育部阳光高考平台核验招生信息

## 34. 仿冒反诈官方渠道（高危新型）

- **话术**：「我们是反诈中心，你的账户有风险，需要转到安全账户保护」「下载我们的反诈 App 核验」「96110 来电让你配合资金清查」
- **硬伤**：**96110 与公安机关不会要求转账、不会索要验证码、不会要求屏幕共享、不会让你下载 App 做「资金保护」**；96110 的职能是预警劝阻与咨询
- **识别**：官方不会通过电话或社交软件「远程办案」；改号软件可伪装 96110，**挂断后自行拨打 96110 回拨核实**

## 35. AI 数字人 / FaceTime 冒充客服

- **话术**：FaceTime 来电自称某平台客服，或视频中出现「AI 客服/AI 主播」引导操作
- **施压点**：视频可信赖度高 + 「百万保障到期扣费」「账户异常需解除」
- **破绽**：要求做指定动作（侧脸、遮挡、念随机数字）即露馅；AI 视频边缘抖动、口型不同步、光线不匹配
- **止损**：挂断，关闭 FaceTime 陌生来电（设置中关闭），通过官方 App 核实

## 36. 恶意 App / 小程序类

- **形态**：仿冒银行/政务/电商 App、含木马的「清理大师」、恶意小程序、含无障碍权限的远控 App
- **危害**：窃取短信验证码、截屏、读取通讯录、拦截银行短信、静默转账
- **硬伤**：**只从官方应用市场下载**；任何索要「无障碍/辅助功能」「设备管理员」「悬浮窗」权限的金融类 App 都是高危
- **止损**：立即卸载、撤销权限（设置 → 无障碍 / 设备管理器）、修改密码、冻结账户

## 技术支撑手段（识别底层特征）

| 手段 | 作用 | 识别特征 |
|---|---|---|
| GOIP / 猫池 | 境外拨号落地为本地号码，隐藏真实位置 | 号码归属地与对方口音、所述单位不符 |
| 伪基站 | 冒用官方号码群发短信 | 短时间内信号异常、短信内容诱导点链接 |
| 改号软件 | 来电显示伪装成官方号码 | 回拨该号码打不通或接通的是真单位 |
| 涉诈 App | 仿冒银行/公检法/投资平台 | 不在官方应用市场、要求安装描述文件、索要无障碍权限 |
| AI 换脸 / 拟声 | 冒充熟人视频或语音 | 画面边缘抖动、口型不同步、声音机械；要求做指定动作即露馅 |
| 屏幕共享 | 实时获取验证码、密码 | 任何要求开启共享的对话都是诈骗 |

## 通用识别口诀（对外宣防用）

> **不听、不信、不转账；不点、不装、不共享。**
> **验证码就是支付密码，谁要都不给。**
> **陌生人谈钱 = 诈骗，熟人谈钱 = 核实。**
