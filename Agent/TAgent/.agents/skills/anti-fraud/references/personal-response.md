# 群众端处置 SOP

顺序不可颠倒：**共情 → 止损 → 固证 → 报案 → 追损 → 防二次**。
先止损再取证——钱还在流动时，多截一张图的价值远低于早一分钟挂失。

---

## 第零步：情绪与状态评估（先于人，再于事）

被骗者此刻通常处于**羞耻 + 恐慌 + 否认**的叠加状态。上来就讲道理或追问细节，会导致对方挂断、隐瞒，甚至回头继续找骗子。

**第一句必须是共情，不是分析**：

> 「不是你的错，骗子专门研究怎么骗人，现在已经这样了，我们一起想办法把损失降到最低。」

**三条表达纪律**：
1. 不评价智商、不说「这么明显」「我早就说过」
2. 不追问「你为什么相信」——时机在止损之后，且要用中性措辞
3. 用「我们」而不是「你」——建立同盟，避免对立

**状态分诊**（决定走哪条路）：

| 状态 | 表现 | 路径 |
|---|---|---|
| 正在操作中 | 「我现在要不要转账」「他还在等我」 | 一句话中止指令 → 直接止损，**不做类型归因** |
| 已转账 / 已泄露 | 「钱已经转了」「验证码给了」 | 共情 → 止损 → 固证 → 报案 |
| 犹豫 / 仅咨询 | 「帮我看看这是不是诈骗」 | 共情 → 进入定性分析 |
| 已被骗且情绪崩溃 | 强烈羞耻、自责、有自伤表述 | **心理干预优先**（12356 心理援助热线）→ 止损由家属或民警协助 |

类型归因（这是哪一类骗局）可以留到用户脱离危险动作之后再补，**止损优先于定级**。

---

## 第一步：止损（黄金 30 分钟）

### 0. 一句话先说
「现在立刻停止转账，不要再和对方说任何一句话。」——这句话必须先于任何解释。

### 1. 切断联系
- 拉黑对方所有联系方式（电话、微信、QQ、短信）
- **不要**先去质问对方「你是不是骗子」——对方会立即转移资金并继续洗脑
- 关闭屏幕共享 / 远程控制：手机下拉菜单、App 内退出；安卓需在设置中关闭「无障碍」授权
- 卸载对方要求安装的 App，撤销设备安装描述文件（iOS：设置 → 通用 → VPN 与设备管理）

### 2. 账户急救（按优先级）

| 顺序 | 动作 | 说明 |
|---|---|---|
| 1 | 拨打 **110**，要求**紧急止付** | 提供收款方账号、转账时间、金额。越早越好 |
| 2 | 冻结自己的转出银行账户 | 银行官方客服电话挂失，或 App 内「一键挂失 / 账户安全锁」 |
| 3 | 修改支付密码 | 微信、支付宝、手机银行、涉及的所有重要账号 |
| 4 | 关闭免密支付 / 快捷支付 | 微信、支付宝、Apple Pay 等逐一检查解绑 |
| 5 | 冻结微信、支付宝账户 | App 内「账号与安全 → 账号冻结」，或客服电话 |
| 6 | 检查是否被诱导开通网贷 | 查询征信报告、各网贷 App 借款记录；发现冒名借贷立即向平台申诉并报案 |
| 7 | 若泄露身份证 | 到「国家政务服务平台」或公安机关备案，关注名下是否被冒名办卡、办公司 |

### 3. 关键认知
- **验证码 = 支付授权**。已告知验证码等同于已授权扣款，必须立即冻结账户而非只改密码。
- 转账后 **30 分钟内**止付成功率显著更高；超过 **24 小时**，资金通常已通过多级账户分散转移。
- 即使钱「还在自己卡里」，只要开过屏幕共享或给过验证码，仍可能被转走，**必须冻结**。

## 第二步：固证（决定后续能否立案、能否追回）

取证清单，逐项打勾：

- [ ] **聊天记录**：完整截图（含对方头像、昵称、ID、时间），不要只截关键几句；导出长图
- [ ] **对方身份信息**：手机号、微信号、QQ 号、银行账号、开户名、收款二维码、平台账号/邀请码
- [ ] **转账凭证**：银行流水截图/回单、微信/支付宝账单详情（含交易单号、时间、金额、收款方）
- [ ] **入口证据**：短信原文、来电号码与通话记录、陌生链接地址、涉诈 App 名称与安装包
- [ ] **平台信息**：投资/博彩平台的网址、App 名、客服账号、充值与提现记录
- [ ] **损失清单**：逐笔列出时间、金额、收款账户、支付方式，汇总总损失

取证要点：
- **不要清空聊天记录**，不要卸载 App（可保留安装包），不要刷机
- 截图要带**时间**和**对方账号**，单独的转账金额截图证明力弱
- 银行流水可到网点打印盖章版本，作为报案材料

## 第三步：报案

### 去哪里
- 已转账或正在被骗 → 直接拨打 **110**，或到**就近派出所**
- 也可到**户籍地或居住地派出所**报案
- 线上渠道：国家反诈中心 App 举报、96110 咨询

### 带什么
身份证原件、涉事银行卡、手机（含全部证据）、转账凭证、损失清单（纸质一份）

### 怎么说（报案陈述模板）

> 我在 **[日期]** 通过 **[渠道，如微信群/陌生来电]** 接触到对方，对方自称 **[身份]**，
> 以 **[事由，如刷单返利/理赔退款]** 为由，诱导我向 **[收款账户]** 转账 **[金额]** 元，
> 共 **[笔数]** 笔，合计 **[总金额]** 元。
> 我发现可疑的时间是 **[时间]**，目前 **[是否已停止转账]**。
> 请求公安机关立案并对收款账户采取紧急止付措施。

### 必须拿到
- **受案回执**（或《立案告知书》）。这是后续查询进展、平台申诉、与银行沟通的凭证
- 报案编号 / 办案民警联系方式
- 明确询问：「对方账户是否已止付冻结？」

### 注意
- 金额不论大小都应报案。小额案件并入串案侦查，是打掉团伙的重要线索
- 报案**不收费**，不存在「立案起点金额」，不要被「金额太小不立案」的说法劝退

## 第四步：追损

| 渠道 | 做法 | 说明 |
|---|---|---|
| 公安止付冻结 | 报案时同步提出 | 最有效，唯一有强制力的途径 |
| 银行 | 申请交易争议核查、提供受案回执 | 24 小时内可尝试撤销（部分渠道支持延时到账撤回） |
| 微信支付 | 账单 → 对订单有疑惑 → 投诉举报 → 选择被骗 | 可冻结对方账户功能 |
| 支付宝 | 账单 → 投诉举报 → 被骗 | 同上 |
| 应用市场 | 举报涉诈 App | 促进下架 |
| 12321 / 国家反诈中心 App | 举报号码、网址、App | 纳入预警库 |

**预期管理**（必须如实告知，不能给虚假希望）：
- 资金一旦进入多级账户并被分散取现或转为虚拟货币，追回难度大、周期长
- 追回进度以公安机关通知为准，任何声称「有门路快速追回」的都是二次诈骗
- 若为被诱导网贷，与贷款机构的债务关系**不因被骗而自动消灭**，需及时与机构沟通并保留报案凭证

---

## 第五步：防二次诈骗（每次都要提醒）

被骗者信息已在黑产流通，二次诈骗高发。必须明确告知：

1. **没有任何「网警/黑客/技术团队」能私下帮你追款**——收费即诈骗
2. **不存在「交保证金解冻被冻结资金」**——只有司法机关能处理
3. **不要下载任何人发来的「退款登记 App」**
4. 自称「律师/维权团队」要求预付服务费 → 核实律师执业证，优先走公共法律服务热线 **12348**
5. 96110 来电务必接听；其他一切「帮你追款」的主动联系，一律按诈骗处理

---

## 附：家人劝阻话术（当事人已被深度洗脑时）

当事人被洗脑时，直接说「你被骗了」通常无效，甚至会使其隐瞒。改用以下方式：

1. **不否定，先争取时间**：「我不反对你赚钱，但这么大金额，咱们先停 24 小时，明天再操作也不迟。」
2. **引导回答具体问题**：「对方公司叫什么？营业执照能查到吗？你见过他本人吗？钱提现过吗？」——让他自己发现矛盾
3. **引入第三方权威**：「我们一起去派出所问一下，如果警察说没问题，我就不拦你。」**陪同前往是关键**，很多时候民警一句话比家人十句有效
4. **直接拨打 96110 或 110 求助**，请求民警上门劝阻（这是 96110 的法定职责之一）
5. **技术止损优先**：若拿不到共识，先做能做的——联系银行对该账户设置转账限额、临时冻结
