# 家属介入机制

当用户是**家属、同事、朋友**，替当事人咨询「ta 是不是被骗了 / 怎么劝 ta」时启用。

定位：**重心是关系与沟通，不是技术拦截。** 硬劝在多数情况下会适得其反——当事人「固执听不进劝」不是态度问题，而是认知失调 + 沉没成本 + 确认偏差 + 维护形象的四重心理锁死。

---

## 一、三阶段识别与干预

干预成功率与阶段成反比，越早越有效。先判断处于哪一期，再选策略。

### 阶段一：情感培植期（约 1–4 周，干预成功率 85%+）

骗子嘘寒问暖、送小礼品、长期陪伴建立信任，**尚无经济损失**。

| 前兆信号 |
|---|
| 频繁接电话且避开家人，压低声音或出门接 |
| 常提某个「新朋友」「好心的老师」 |
| 对健康、投资、理财话题异常兴奋 |
| 热衷免费讲座 / 免费旅游 / 免费体检 |
| 频繁收快递、小礼品 |
| 手机里出现不明 App |
| 开始囤积保健品、藏品 |

**有效干预**（此时成本最低）：
- 设一个**家庭暗号**，涉及钱必须报暗号
- 安装国家反诈中心 App，开通**转账实时提醒**
- 关闭免密支付与小额免验
- 聊天式分享反诈新闻，**不对号入座、不说教**
- 填补孤独：常回家、定期打电话——被骗往往源于情感空缺

### 阶段二：利益诱导期（约 1–2 周，干预成功率 50–60%）

骗子引导小额投入并先给甜头，建立「这人靠谱、这事能赚」的确认。

| 前兆信号 |
|---|
| 小额频繁转账或取现 |
| 定期存款提前支取 |
| 大量购买购物卡、充值卡 |
| 账户出现陌生收款方 |
| 突然「手头紧」，日常开支却说不清 |
| 拒绝家人看银行流水 |
| 对某个「投资机会」异常兴奋但不透露细节 |

**有效干预**：
- 用「我们」语言，不指责：「我们一起看看这个靠不靠谱」
- 说「我帮你参谋参谋」，而不是「你别被骗了」
- 用**同龄人、同社区的真实案例**引导，比讲道理有效
- 用权威代替家人：医生、社区民警、电视节目
- 给老人安排「任务」，填补被需要感（骗子给的就是这个）
- **允许反复**：不强迫承认被骗，很多人宁愿继续被骗也不愿承认错了

### 阶段三：深度控制期（干预成功率 <30%，需紧急行动）

已发生大额资金转移，对方要求保密、隔绝家人，当事人被沉没成本锁死。

| 前兆信号 |
|---|
| 大额转账或取现 |
| 拒绝接子女电话、躲着家人 |
| 神色慌张外出取钱，或有陌生人上门取现金 |
| 坚持保密、对被问起异常敏感 |
| 以房抵押、改遗嘱、改保险受益人 |
| 借高利贷「投资」 |
| 情绪崩溃或自我封闭 |

**紧急行动**：
1. 立即 **110 或 96110**，请求民警上门劝阻（这是 96110 的法定职责）
2. 联系银行**紧急止付 / 冻卡**
3. 保留全部记录（聊天、转账、快递单、合同）
4. 切断与骗子的联系通道
5. 暂管财务——**非指责式表达**：「我先帮您管几天，怕再有骗子找上门」
6. 心理安抚重于追责：「不是你的错，骗子专门研究这个，我们一起想办法」

## 二、该说 vs 绝不能说

### 该说

| 场景 | 推荐话术 | 为什么有效 |
|---|---|---|
| 日常预防 | 「最近看到好多这种新闻，咱一起打个预防针」 | 不针对个人，降低防御 |
| 发现苗头 | 「我同事说他爸妈也遇到过类似的，后来发现是骗局」 | 第三方视角，不否定当事人 |
| 劝阻购买 | 「听说你买了好东西，也给我讲讲？」 | 先共情，再找机会替代 |
| 涉及转账 | 「这么大笔钱，咱商量商量，我也想学学」 | 让当事人感到被尊重、有价值 |
| 已被骗 | 「不是你的错，骗子专门研究怎么骗人，我们一起想办法」 | 消除羞耻感，建立同盟 |

### 绝不能说

| 禁忌 | 后果 |
|---|---|
| 「你怎么这么傻」 | 更封闭，拒绝沟通 |
| 「说了多少遍了别信」 | 产生防御，更亲近骗子 |
| 「这么明显都看不出来」 | 因羞耻而隐瞒，从此不再求助 |
| 「你再买我就不管你了」 | 当事人会在家人和骗子之间选骗子 |
| 「让我看看你的银行流水」 | 感到被控制，更不愿透露 |
| 「你是不是糊涂了」 | 彻底破坏信任 |

## 三、介入三步法

1. **先站队**：「我们先把钱保住，不是怪你」——先站到当事人一边
2. **再断联**：协助挂断电话、退出群聊、停止转账
3. **后核验**：陪同拨打官方电话、去银行网点或派出所

**争取时间的缓兵之计**（当事人执意要转账时）：
> 「我不拦你赚钱，但这么大金额，停 24 小时再操作也不迟。明天我陪你去银行。」

只要争取到时间，民警介入的成功率会大幅上升。

## 四、介入者边界

- 介入者**不是执法者**：不搜证、不审讯、不监视，只做提醒与陪同
- 当事人拒绝介入时，保留求助通道（96110 / 110 / 社区民警），不要硬压
- 怀疑已大额受损 → 直接建议报警，**不自行「追款」**（网上的追款团队全是二次诈骗）
- 当事人出现严重情绪危机、自伤风险或强烈羞耻封闭 → **转介 12356 心理援助热线**，心理干预优先于追责
- 保护介入者自身：不要替当事人承担资金责任，不要签署任何代偿文件
